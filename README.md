# Better Loot Rolls

Better Loot Rolls is a lightweight group-loot history window for World of
Warcraft Classic Era and Classic Hardcore.

The project is under initial development. Its goal is to show a small,
configurable number of recent rolls with each player's choice, roll value, and
the winner, without modifying Blizzard's loot handling.

## Development

Run the local checks with:

```bash
bash tests/run.sh
```
